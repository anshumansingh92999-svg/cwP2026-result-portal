# CWP 2026 – Online Examination & Result Management System

## 📌 Project Overview

CWP 2026 is a web-based examination and result management system developed to manage student examination records and provide students with online access to their results and answer sheets.

## 🎯 Objectives

- Digitize examination result management
- Allow students to access results online
- Connect results with specific paper codes
- Provide access to corresponding answer sheets
- Reduce manual result distribution
- Provide a mobile-friendly interface

## ✨ Features

- Student ID based identification
- Paper Code based result access
- Marks/result display
- Answer-sheet viewing
- Responsive web interface
- Online deployment using GitHub Pages

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages
